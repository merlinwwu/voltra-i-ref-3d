|---|---|

| 子系统 | CAB / LW / EXIT |
| 关键机构 | **两种实施例。** ① 摆动式：摆座绕出线口摆动，带出线臂，用自锁蜗轮 510 + 蜗杆 530 驱动，摆角由霍尔/磁环检测，限位微动开关 102，出线处有导向对轮。CN122233236A 权利要求 2–5 写到：两根臂沿径向向外伸出，两臂间设导轮，并有限位框和对轮。② 滑动式（图 6–8）：滑座 321 在光轴 322 上经直线轴承 323 滑动，由自锁蜗杆螺母 520 驱动，滑座上有转动座 326 和转向轮 328/329，出线轮 710（其中一只带阻尼）。CN122166625A 的权利要求写到"转动座 + 第一/第二转向轮"。**同步关系：卷筒每转一圈，排线移动一个绳径。** |
| 对照 | ✅ **采用滑动式**：小车 LW-CAR-01 = 滑座 321；导杆 LW-ROD-01 = 光轴 322；衬套 LW-BUSH-02 对应直线轴承 323（用 iglidur 衬套代替，原因是空间不够，且衬套只承受防转载荷）；Tr10×2 自锁丝杠 + 青铜螺母对应自锁蜗杆螺母 520；转向座 EXIT-SWV-01 = 转动座 326；导轮 LW-ROL-01 = 转向轮 328/329。同步：齿轮 z56/z35，i=1.6，小车每转进给 3.2 mm，等于槽距，误差为 0。◐ 专利写"每转 1 个绳径"，本设计取 1.07d（3.2 mm），以留出槽间隙。◐ 出线轮 710 的阻尼没有采用，绳端由电机闭环控张。✖ **不采用摆动式**。`cad/lw_study.py` 的计算结果：在 R20 单层缠绕下，绳在卷筒上的行程是 66.2 mm；摆臂在 139 mm 截面内最长只能做到 37.5 mm，需要约 79° 的摆角，蜗轮要承受约 31 N·m，m0.5 的 POM 蜗轮承受不了。v01 用的正是摆动式，所以 v01 不可行。 |

### 1.3 卷筒散热结构 —— CN220327890U（授权）

| 项 | 内容 |
|---|---|
| 关键机构 | 绕线轮 = 塑料内芯 + 导热更高的金属外壳；两者用轴向筋/槽传扭；内芯与外壳之间留散热通道。 |
| 对照 | ◐ 本设计的卷筒整体用 6061-T6 铝，并做硬质阳极。理由：单层缠绕时箍压应力约 45 MPa，塑料内芯会蠕变。卷筒中段做了 Ø26 减重孔，可兼作风道。没有采用双材料结构，因为零件更少、同轴度更容易保证。 |
| 结论 | 一致性：部分一致。可加工（车削 + 螺纹车槽，或旋风铣槽）。 |
