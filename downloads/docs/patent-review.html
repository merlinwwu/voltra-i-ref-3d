1. 机械相关专利：详细审查

1.1 排线（level-wind）—— CN220223097U（授权）、CN118529559A（待审）及其分案 CN122166625A / CN122233236A

项 内容
专利 CN220223097U《排线绕线机构及出力设备》，公告日 2023-12-22，有效；CN118529559A 发明申请，公开日 2024-08-23，待审；分案 CN122166625A（滑动式，2026-06-09）、CN122233236A（摆动式，2026-06-19）
子系统 CAB / LW / EXIT
关键机构 两种实施例。 ① 摆动式：摆座绕出线口摆动，带出线臂，用自锁蜗轮 510 + 蜗杆 530 驱动，摆角由霍尔/磁环检测，限位微动开关 102，出线处有导向对轮。CN122233236A 权利要求 2–5 写到：两根臂沿径向向外伸出，两臂间设导轮，并有限位框和对轮。② 滑动式（图 6–8）：滑座 321 在光轴 322 上经直线轴承 323 滑动，由自锁蜗杆螺母 520 驱动，滑座上有转动座 326 和转向轮 328/329，出线轮 710（其中一只带阻尼）。CN122166625A 的权利要求写到"转动座 + 第一/第二转向轮"。同步关系：卷筒每转一圈，排线移动一个绳径。
对照 ✅ 采用滑动式：小车 LW-CAR-01 = 滑座 321；导杆 LW-ROD-01 = 光轴 322；衬套 LW-BUSH-02 对应直线轴承 323（用 iglidur 衬套代替，原因是空间不够，且衬套只承受防转载荷）；Tr10×2 自锁丝杠 + 青铜螺母对应自锁蜗杆螺母 520；转向座 EXIT-SWV-01 = 转动座 326；导轮 LW-ROL-01 = 转向轮 328/329。同步：齿轮 z56/z35，i=1.6，小车每转进给 3.2 mm，等于槽距，误差为 0。◐ 专利写"每转 1 个绳径"，本设计取 1.07d（3.2 mm），以留出槽间隙。◐ 出线轮 710 的阻尼没有采用，绳端由电机闭环控张。✖ 不采用摆动式。cad/lw_study.py 的计算结果：在 R20 单层缠绕下，绳在卷筒上的行程是 66.2 mm；摆臂在 139 mm 截面内最长只能做到 37.5 mm，需要约 79° 的摆角，蜗轮要承受约 31 N·m，m0.5 的 POM 蜗轮承受不了。v01 用的正是摆动式，所以 v01 不可行。
结论 滑动式可加工、可装配、可工作（自锁条件 λ 4.05° < φv 5.9°；螺母 pv = 2.2 MPa·m/s，青铜许用 ≤ 3）。照片 01/02 中的"黑色摆环 + 白色蜗轮扇形"更像摆动式，和"单层 R20"相矛盾，列为待用户决定的事项 D1。

1.2 万向出线 —— CN220213802U（授权）

项 内容
专利 CN220213802U《万向出线机构及出力设备》，公告日 2023-12-22，有效
子系统 EXIT
关键机构 底座 + 经轴承转动的旋转座 + 成对出线轮 + 条形抛光金属导线块（喇叭状张开），出线方向可以随拉绳方向转动。
对照 ◐ 机内部分：旋转座 = EXIT-SWV-01（上 61804 + 下 6000 双支承，绳在座内 90° 转向后沿转轴引出），已采纳。◐ 机外部分：用整圈抛光不锈钢喇叭口 EXIT-GUIDE-01（R ≥ 6，Ra0.1）代替"旋转对轮 + 导线块"。原因：前板厚度和包络里放不下第二套旋转轴承。代价是侧拉时绳在喇叭口上滑动，磨损更大，所以把绳定为可换件（官方本来就支持换绳）。可以升级为专利式结构，见 D3。
结论 可工作；出线罩比包络凸出 4.5 mm（照片 05 中原机的白罩也是凸出的），见 D2。

1.3 卷筒散热结构 —— CN220327890U（授权）

项 内容
关键机构 绕线轮 = 塑料内芯 + 导热更高的金属外壳；两者用轴向筋/槽传扭；内芯与外壳之间留散热通道。
对照 ◐ 本设计的卷筒整体用 6061-T6 铝，并做硬质阳极。理由：单层缠绕时箍压应力约 45 MPa，塑料内芯会蠕变。卷筒中段做了 Ø26 减重孔，可兼作风道。没有采用双材料结构，因为零件更少、同轴度更容易保证。
结论 一致性：部分一致。可加工（车削 + 螺纹车槽，或旋风铣槽）。

1.4 绳端锚固 —— CN220596688U（授权）、CN220906831U（授权）

项 内容
CN220596688U 卷筒端部设固线位，压线块装在里面；压线块有弧形压槽和交错压齿，用螺钉锁紧。
CN220906831U 弧形绕线盘上开多个穿线孔/通道，供绳端编织穿插，外加保护盖。
对照 ✅ 左挡边外侧开 10×13.5×4.5 凹槽；绳经 Ø3.4 轴向孔从槽底进入凹槽，由 DRUM-CLAMP-01 压线块 + M3 沉头螺钉压紧。另留 3 圈死圈：按绞盘公式 e^(−μθ)，μ = 0.1、θ = 6π，锚固点只受约 15% 的绳力，约 120 N。✖ 编织穿孔方案（CN220906831U）没有采用，因为它更适合大直径盘。
结论 可加工、可装配（换绳时取下电池仓盖，从卷筒仓前窗口就能拧到压线块螺钉）。

4. 对 CAD-v02 的影响汇总

  1. 排线：摆动式 → 滑动小车 + Tr10×2 自锁丝杠 + z56/z35 齿轮同步（专利 1、2、3）。这是 v01 → v02 最大的改动。
  2. 出线：双支承旋转座 + 转向轮（专利 5），机外改为固定喇叭口。
  3. 卷筒：槽距 3.2，25 圈，左旋；压线块锚固（专利 7）；铝卷筒（专利 6 部分采纳）。
  4. 转子毂内置风扇、磁环、花键（专利 15）。
  5. 制动电阻导热垫 + NTC（专利 10）；Dock 枢转卡钩 + 法兰承压（专利 20–22）。
  6. 待决事项 D1–D5、未知项 U1–U3 见 gap-list.md §0。
