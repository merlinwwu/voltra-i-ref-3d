# CAD-v03 装配顺序（ASSY-01）

> v03 变更：排线改为**自锁蜗杆 + 摆动蜗轮扇形**（用户决定 D1，专利 CN122166625A / CN122233236A 摆动式）。B、D 两节已重写，A 节增加惰轮销，C 节改为 R25 卷筒，F 节改为摆动检查。v02 版本备份：`assembly-sequence_v02.md`。

所有扭矩都按干态、8.8 级（M5 用 12.9 级）、K≈0.2 计算。"胶"指中强度螺纹胶（Loctite 243 类）。图号见 `site/downloads/drawings/`，序号见 ASSY-01-BOM。

## A. 电机模块（MOT-HSG-01 为基体）
1. MOT-HSG-01 定子孔清洁、底涂后，涂 Loctite 638 类胶，压入 MOT-STAT-01：轴向位置 x 76，出线朝 PCB 侧。按胶的说明固化。
2. 转子组件：ROT-01 胶接到 ROT-HUB-01 的 Ø58.42 g6 外圆。ROT-HUB 腹板通过 2×Ø3 销定位到 MOT-SHAFT-01 法兰，6×M4×12 加胶，拧紧 3.0 N·m（对角分 2 遍）。转子组件动平衡 G6.3。
3. MOT-SHAFT-01 压装 BRG-01（6003-2RSH，压力只加在内圈），装 SPC-BRG01（配磨厚度 3.70）。
4. 从电机壳的卷筒侧装入转子 / 轴组件：BRG-01 外圈 K6 压入座孔（压力只加在外圈），装 CLP-BRG01（DIN 472-35）。工具：挡圈钳 J2。
5. ENC-MAG-01 胶接到轴尾。
6. HSG-END-R-01：先装 BRG-02，外圈 H7 滑入；装 WSPR-BRG02 波形弹簧和 ENC-PCB-01（3×M2，0.3 N·m）。整体套到轴尾和止口上，装 CLP-BRG02（DIN 471-17）。
7. 检查：转子用手转应顺畅，轴向游隙 0.05–0.15。

## A2. 惰轮（必须在卷筒之前）
7a. LW-IDL-BUSH-01（烧结青铜 Ø5/Ø8×4，s7）压入 LW-IDL-01（z24）。惰轮套到 LW-IDL-PIN-01 上，用压头把销压入 MOT-HSG 端面的 Ø5 R7 孔（深 10），头部留 0.1 轴向间隙。原因：装上卷筒后，卷筒挡边 r28 挡住压头通道。

## B. 排线子组件（工作台上完成）
8. **蜗杆箱 LW-BOX-01**：
   - HK0608（LW-NDL-01）压入左座 Ø10 N7，压力只加在外圈；
   - 装 626 座左侧挡圈 CLP-LW-01（DIN 472-19）；
   - LW-WORM-01 从右侧穿过 Ø19 通孔（蜗杆齿顶 Ø17.6 可以通过），左轴颈 Ø6 h5 插入 HK0608；
   - LW-BRG-01（626-2RS）套到右轴颈上，外圈推入 Ø19 孔贴紧左挡圈，再装右挡圈 CLP-LW-01。626 是固定端，承受蜗杆轴向力（满载 421 N）；
   - 依次装 LW-SPC-01、LW-GEAR-01（z21），打入 PIN-LWG-01（Ø1.5 弹性销，孔为预钻，不需要配钻），装 CLP-LW-02（DIN 471-6）；
   - 检查：蜗杆手转顺畅，轴向游隙 ≤ 0.05。
9. **摆座子组件**：
   - EXIT-PIN-01（Ø12 p6）从上方压入 LW-BRIDGE-01，肩部 Ø15 贴紧桥架顶面；
   - EXIT-BRG-02（6201）从上方压入 EXIT-SWV-01 毂孔 Ø32 K6，贴紧底部挡肩 Ø27。这个挡肩承受外拉轴向力 F；
   - EXIT-BRG-01（6201）外圈涂 638 胶后压入，与下轴承紧贴；
   - 摆座套到摆轴销上，两只内圈 k5 推入，下轴承内圈贴住销肩，装 CLP-EXIT-01（DIN 471-12）；
   - LW-MAG-01 磁环胶接到毂外圆，零极对准叉板中心线（刻线）。
10. **转向轮**：EXIT-SHV-01 压入 HK0608（EXIT-NDL-01），用 EXIT-AXL-01 装入叉板，两端 DIN 6799 挡圈。
11. **导线臂**：
    - 两个 LW-ROL-01 各压一个 HK0608（LW-NDL-02），套到 LW-PIN-01 上，销压入 LW-ARM-01（p6），下端装 E 型挡圈；
    - LW-WHEEL-01 蜗轮扇形用 4×M3×6 ISO 10642（加 243 胶，1.0 N·m）固定到导线臂；
    - 导线臂用 4×M3 ISO 10642（加 243 胶，1.2 N·m）固定到摆座的臂安装座。
12. LW-HALL-01 霍尔板（M2.5）和两只 LW-LIMIT-01 限位开关装到桥架上。限位凸块朝向卷筒一侧，触发角 ±43.4°，工作角 ±41.4°。

## C. 卷筒模块
13. 4×PIN-DRUM-01（Ø3 m6×7）压入 DRUM-HUB-01 法兰的 N7 孔（PCD32）。DRUM-01（R25 单层，21 圈，槽距 3.2 左旋）的 G7 孔对准销，从止口推入。
14. 绳端：DRUM-CLAMP-01（M3×10 加胶，1.0 N·m）压住绳头，按左旋方向缠 3 圈死圈。剩余绳长等全部装完后再收卷。
15. DRUM-01 左轴颈装 BRG-03 和 CLP-BRG03。BRG-03-HSG 外圈 G7 滑入（浮动端）。
16. 卷筒组件的内花键推入 MOT-SHAFT-01：推入的同时微转卷筒，让 z35 和已装好的惰轮 z24 沿轴向进入啮合。
17. SCR-DRUM-01 从左端经空心轴颈拧入，5.5 N·m，加胶。

## D. 核心骨架、摆座、蜗杆箱和定相
18. HSG-FRAME-01：BRG-03-HSG 止口入 H8，4×M3×8 拧紧，1.1 N·m。
19. 桥架子组件（含摆座和导线臂）：左端用 M4×14 + Ø3 销（PIN-BRG-01）固定到中隔板，2.6 N·m；右端 Ø6 g6 止口销插入 MOT-HSG。
20. 穿绳：绳从卷筒出绳切点沿 +Y 进入两只对轮之间（间隙 3.3），沿导线臂绕过中心转向轮 90°，再沿摆轴向上穿出。绳头先从 EXIT-BASE 的导绳孔穿出。
21. **定相（关键步骤）**：
    - 卷筒转到第 1 工作圈起点：锚固块后第 4 圈的槽口对准出绳切点（+Z 顶点），这对应"绳全放出"位置；
    - 摆座转到 θ = −41.4°，用霍尔读数（维修固件）或定相样板 LW-JIG-01（工装，未建模）确认；
    - 对应关系：全收绳 ↔ θ = +41.4°，全放出 ↔ θ = −41.4°，卷筒每转 5.000°。
22. **装入蜗杆箱**：LW-BOX-01 子组件沿 −Z 方向落入：
    - 蜗杆沿蜗轮齿槽的齿宽方向滑入啮合；z21 同时沿径向进入和惰轮 z24 的啮合；
    - 惰轮相位最多差半个齿，换算到摆角 ≤ 0.07°（导轮横向 ≤ 0.05 mm），可以忽略；
    - 隔板侧：Ø3 销（PIN-LWB-01）+ 2×M3×12 ISO 10642，1.1 N·m；电机壳侧：2×M3×8 加 243 胶，1.1 N·m。
23. 检查侧隙：在导线臂端部测量蜗杆副侧隙，目标 0.05–0.12。中心距 56 由隔板、电机壳和桥架的销定位保证，RSS ≈ ±0.035。如果侧隙不合格，修磨电机壳侧的安装面，或者更换蜗杆箱。
24. 手转卷筒一个全行程（16.6 圈）：摆座 −41.4° → +41.4°，全程不卡滞，导轮中心与绳槽的横向误差 ≤ 0.8 mm（理论最大值 0.72）。

## E. 电子和壳体
25. 电子：
    - PCB-HS-01 加 TIM 贴背壁；
    - PCB-MAIN-01 4×M3×6，0.6 N·m；
    - 制动电阻加导热垫，2×M4×8，2.0 N·m；
    - DOCK-IF-01 法兰贴下壳内壁，4×M3 沉头（1.0 N·m），装卡钩、销和 SMART-LOCK。
26. 核心模块（电机 + 排线 + 卷筒 + 出线 + 隔板）放入下半壳。分型面贴 0.8 mm EPDM 条，合上上半壳（2×Ø3 销定位）。
27. 4×BOLT-TIE-01（M4×102）从右端盖把手开口内插入，用 L 型扳手拧入主壳凸台（钢丝螺套），2.5 N·m。
28. EXIT-BASE 的 4×M3 沉头拧入壳体凸台，1.1 N·m（底板下表面有让位：转向轮扫掠 Ø41×1.2、626 座 R11.6；v03 中底板不再承受出绳轴向力）。EXIT-GUIDE-01 装入 EXIT-UNI-01，3×M3×8，0.8 N·m。贴 LBL-SAFETY-01。
29. 电池仓：BAT-MOD-01 插入 BAT-CONN-01，HSG-END-L-01 用 4×M4 ISO 10642 拧紧，2.6 N·m。
30. 绳头：CONN-01 绕线加卡口。

## F. 出厂检查
31. 空载：卷筒正反转全行程（16.6 圈），摆座 ±41.4° 平顺，霍尔角度与卷筒编码器换算值之差 ≤ 0.3°；两个限位开关只在人为超程时触发（±43.4°）。
32. 绳收满后检查：第一圈和最后一圈都在槽内，不跳槽、不叠绳；最大偏角目视 ≤ 2°。
33. 静止自锁：断电后，在导线臂上施加 ±20 N·m 的扭矩，摆座不得转动（静摩擦 μs ≥ 0.08 时自锁）。
34. 加载 785 N 静拉 60 s：分别在 θ = −41.4°、0°、+41.4° 三个位置各做一次，各处无异响，壳体无可见变形，蜗杆副侧隙没有变化。
35. 记录电机电流、绳长零点、编码器零点和霍尔零点。
