§4 绳路 ◐

  • 绳路：卷筒顶点 z = R = 25 → 沿 +Y 进入两只导向对轮（Ø13，间隙 3.3）→ 在内侧对轮上转过 θ → 沿导线臂到中心转向轮（槽底 Ø14.6）→ 转 90° 沿摆轴上行 → 喇叭口 → 绳头。
  • 出线口到卷筒接触点的距离基本不变：摆座绕出线口轴线转动。
  • D/d：
  • 卷筒 16.7（v02 为 13.3）；
  • 导向对轮 4.3：包角 ≤ θ，最大 41°，满载径向 555 N；
  • 中心转向轮 4.9：包角 90°，满载。
  • 结论：能工作，但中心转向轮是主要疲劳点，绳定为可换件。可选项见 §0 的"转向轮 Ø26"。
  • 喇叭口：喉部 Ø5，出口 R ≥ 6，Ra0.1。

§5 排线同步、自锁、端部 ✅

  • 运动链：卷筒 1 转 → z35 → z24（惰轮）→ z21 → 蜗杆 1.667 转 → 蜗轮 z120 → 摆角 5.000° → 对轮横向位置 x = XO + Rs·sin θ（Rs 38.98）。
  • 行程：16.55 个工作圈，θ 从 −41.38° 到 +41.38°。全放出对应 −41.4°，全收绳对应 +41.4°。
  • 同步误差：全行程最大 0.716 mm，为正弦误差，不累积。偏角名义 1.15°，最坏 1.69°（含 0.3 mm 间隙），满足 ≤ 2°。
  • 自锁：λ 2.862° < φ'（μ0.05 时 3.046°），正向效率 0.48，静止时反驱效率 < 0。运行中的风险见 D8。
  • 端部：
  • 两只限位开关在 ±43.4° 触发（工作 ±41.4°）；
  • 软件按卷筒编码器和霍尔摆角做双重限位；
  • 绳的两端（全收和全放）本身就限定了卷筒转角，所以正常情况下摆座不会超程。
  • 侧隙和中心距：a = 56 由隔板、电机壳和桥架的销定位链保证，RSS 约 ±0.035。满载时桥架和摆轴销变形会让中心距变化约 0.036 mm，小于侧隙 0.08。

§14 v03 相对 v02 的修改

  1. 排线：滑动小车 → 自锁蜗杆 + 摆动蜗轮扇形（D1）。删除 LW-SCREW / LW-NUT / LW-CAR / LW-ROD / LW-END-L 等零件，新增 LW-WORM / LW-WHEEL / LW-ARM / LW-BOX / LW-IDL / LW-HALL / LW-MAG 等。
  2. 卷筒 R20 → R25，21 圈；传扭销 Ø4 → Ø3（PCD32，避让惰轮销头）。
  3. 电机 MF0095044 → MF0095056（叠长 43.2 → 55.2），MOT-HSG 绕组腔加长。
  4. 摆座：v02 的 61804 + 6000（经底板支承）改为桥架上的悬臂摆轴销 + 2×6201 紧贴。外拉力 F 不再经过底板。
  5. 改为 6201：起初用的 2×6001 跨距只有 9，s0 只有 1.4，不满足。
  6. 惰轮 z24：原本蜗杆轴齿轮会顶到前壁，所以加惰轮，并保证 z21 ≤ 21。
  7. 蜗杆 d1 13 → 16：把自锁门槛从 μ 0.058 降到 μ 0.05。
  8. 贯穿螺栓 (30, 40) → (57, 40)，为蜗轮扫掠让位。
  9. 限位凸块改朝卷筒侧，桥架局部加宽，避开壳体内壁。
  10. 壳体和电机壳增加局部让位（§10）。
  11. 蜗轮扇形原来按实心扇形建模（165 g），改为齿圈 + 腹板 + 减重窗（约 47 g）。
  12. 运动包络检查发现扇形扫到底板螺钉凸台：扇形 ±50° 改为 ±47°（在 ±43.4° 限位处，啮合区仍有约 1 齿余量），上面两颗底板螺钉外移到 (−52.5, 51) / (35.5, 51)。
  13. 工程图：改用紧包围盒，修正非回转件高度尺寸显示错误（v02 图上非回转件的高度尺寸数值错误，例如 DOCK-HOOK-01 高 8 显示成 4000），所有图纸已重出。
